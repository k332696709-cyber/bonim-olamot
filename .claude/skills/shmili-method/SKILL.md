# בונים עולמות - שיטת שמילי

מקור ההשראה: https://shmili.co.il/ ("מבחוץ אתר. מבפנים מערכת."). הצבעים והתוכן הם של בונים עולמות, העיצוב והתנועה הם בסגנון שמילי.

## עיקרון
מערכת שעובדת בשביל הצוות: כל פנייה מקבלת מענה, שום דבר לא נופל, והשדכנים והמנהל לא נושאים את העול הטכני. מדד לכל פיצ'ר: כמה זמן הוא חוסך ואיזו משימה הוא מטפל בה לבד.

## מערכת העיצוב (לא לשנות בלי בקשה)
- **צבעים:** כחול נייבי `navy` (`#003366`, כהים `#001529`) ובורדו `burgundy` (`#800020`). גווני הבורדו הבהירים (300/400) הם **אדום אמיתי**, לא ורוד. אין להחזיר ורוד.
- **פונט:** IBM Plex Sans Hebrew בכל האתר (גם `font-serif` ממופה אליו).
- **מראה:** כותרת צפה בכמוסה לבנה, מקטעים כהים/בהירים לסירוגין עם רשת עדינה, כרטיסים `rounded-[28px]`, כפתורים בכמוסה (`rounded-full`), פס מתגלגל, מחלקות `hero-dark` / `hero-burgundy` ב-`globals.css`.
- **שפות:** עברית (RTL) ואנגלית. טפסי ההרשמה הם בעברית בלבד, כמו Tally.
- **ניסוח:** ניטרלי למין כשלא ידוע (מקליד/ה, מחובר/ת, העוזר/ת).

- **סודות:** סיסמאות, מפתחות API וטוקנים לא נכתבים בקוד, בקבצי SQL או ב-git. הם נשמרים ב-Supabase/Vercel בלבד.

- אפיון קודם, קוד אחר כך. אם הבקשה עמומה, שואלים שאלה קצרה.

## בדיקות לפני סיום
`npx tsc --noEmit`, `npm run build` (לעצור קודם את שרת הפיתוח כדי לא להשחית את `.next`), ובדיקה בדפדפן בעברית, באנגלית ובמובייל.
